# ABASlib
### О проекте

**ABASlib** - это сайт для просмотра и чтения комиксов/манг/книг с системой аккаунтов. Для реализации в основе используется **Python + Django + JS (минимально)**.

Структура проекта:
Приложение состоит из нескольких Django-приложений, каждое из которых выполняет определенную роль

### Приложение `catalog`

  Каталог тайтлов, поиск и фильтрация 
  
### Приложение `users`
  
  Операции с пользователями, авторизация, профили
  
### Приложение `reader`
    
  "Читалка" с закладками: чтение произведений

### Приложение `metadata`
    
  Метаинформация о произведениях, теги, жанры, статистика

### Приложение `titles`
    
  Произведения и операции с ними

### Приложение `ratings`
    
  Система оценок к произведениям

### Приложение `comments`
    
  Комментарии от пользователей
